# Activity

## Transaction History

The **Activity** menu displays all your wallet transactions with information:

- Type (Send/Receive)
- Amount and token
- Status
- Date
- Direction (inbound/outbound)
- Recipient/sender address

## Filters

- **Token** — USDC, EURC, or All
- **Direction** — Inbound, Outbound, or All
- **Search** — Search by address or amount

## Export

- **Export CSV** — Download as CSV file
- **Export Excel** — Download as CSV with BOM (can be opened in Excel)
- **Export PDF** — Print via browser print dialog

> ⚠️ Transaction data comes from Arc Testnet. It has no real value.
