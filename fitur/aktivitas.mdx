# Activity

## Riwayat Transaksi

Menu **Activity** menampilkan semua transaksi wallet Anda dengan informasi:

- Tipe (Send/Receive)
- Jumlah dan token
- Status
- Tanggal
- Arah (masuk/keluar)
- Alamat tujuan/pengirim

## Filter

- **Token** — USDC, EURC, atau All
- **Direction** — Inbound, Outbound, atau All
- **Search** — Cari berdasarkan alamat atau jumlah

## Export

- **Export CSV** — Unduh sebagai file CSV
- **Export Excel** — Unduh sebagai CSV dengan BOM (bisa dibuka di Excel)
- **Export PDF** — Cetak via browser print dialog

> ⚠️ Data transaksi berasal dari Arc Testnet. Tidak memiliki nilai riil.
