# Wallet Security

## Security Model

- **No MetaMask** — Wallets are managed server-side via Circle Developer-Controlled Wallets.
- **Auto-provision** — Wallet is automatically created on Google login. No seed phrase is stored in the browser.
- **Server-side policy** — Transaction validation is performed on the server, not the client.
- **Session-based** — Wallet access is tied to the login session.

## Network

- **Arc Testnet** (Chain ID 5042002)
- RPC: `https://rpc.testnet.arc.io`
- Gas fee paid with USDC (native gas token on Arc)

## Important Notes

- Funds on Arc Testnet **have no real value**.
- Do not send assets from other networks to Cirata addresses — it may cause loss of funds.
- Circle API key and entity secret are stored server-side, not exposed to the browser.

> Cirata is in development phase. Always verify transactions on [Arc Explorer](https://testnet.arcscan.app) before considering them final.
