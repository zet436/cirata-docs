# Pertanyaan Umum

## Apa itu Cirata?

Cirata adalah dashboard treasury USDC/EURC di Arc Testnet. Wallet otomatis dibuat saat login Google.

## Apakah butuh MetaMask?

Tidak. Wallet dikelola server-side via Circle. Anda tidak perlu install wallet extension.

## Dana riil?

Tidak. Semua dana di Arc Testnet tidak memiliki nilai riil.

## Kenapa saldo 0?

1. Pastikan sudah login
2. Tunggu 1–3 detik setelah login (wallet provisioning)
3. Refresh halaman
4. Cek apakah ada transaksi masuk di Arc Explorer

## Export data bagaimana?

Buka menu **Activity**, lalu klik **Export CSV**, **Export Excel**, atau **Export PDF**.

## Voice command untuk apa?

Mengisi form transfer via suara. Tekan tombol mikrofon di halaman Transfer.

## Siapa yang bisa menggunakan?

Siapa saja dengan akun Google. Wallet otomatis dibuat per email.

## Bagaimana cara menerima dana?

Buka Treasury → **Show QR for Receiving**, lalu bagikan alamat atau QR code ke pengirim. Pastikan pengirim menggunakan Arc Testnet.
