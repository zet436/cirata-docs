# Cirata

Cirata is a web treasury management app for **USDC** and **EURC** on **Arc Testnet**.

## Key Features

- **Treasury** — View balance, inflow/outflow, and performance charts.
- **Transfer** — Send tokens to a 0x address with confirmation.
- **Activity** — Transaction history with filters and export.
- **Settings** — Account preferences and theme.

## How It Works

1. Log in via Google.
2. The system auto-creates a Circle Developer-Controlled wallet for your email.
3. Use the dashboard to check balance, transfer, and view history.

> ⚠️ Cirata runs on **Arc Testnet**. Funds shown have no real value.
